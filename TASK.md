# TASK - Dashboard Focus Quick Edit

## Goal

Let the user quickly edit today's `Main Focus` and `Morning Intention` directly from the Dashboard.

## Source of Truth

Read these files first:

- `docs/fsd/00_master_index.md`
- `docs/fsd/05_data_model.md`
- `docs/fsd/06_functional_requirements.md`
- `docs/fsd/08_technical_architecture.md`
- `docs/fsd/10_testing_release.md`

## Requirements

1. Keep loading local tasks and today's DailyPlan.
2. Show `Main Focus` and `Morning Intention` clearly in the Today’s Focus card.
3. Add a compact quick-edit option on the Dashboard focus card.
4. Let the user save `Main Focus` and `Morning Intention` from the Dashboard.
5. Keep Planner and Dashboard in sync after save.
6. Add focused widget coverage for Dashboard focus editing.
7. Keep related project / clear focus / focus reason out of scope for now.

## Expected Result

The Dashboard should let the user quickly update today’s focus without leaving the home screen.

Saved focus values should persist locally and immediately reflect in Planner and Dashboard.
