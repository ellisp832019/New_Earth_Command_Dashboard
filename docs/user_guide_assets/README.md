# Users & Devices Visual Assets

This folder holds printable visual support material for the Users & Devices guide.

- `users_devices_onboarding_handoff_cheatsheet.svg`
- `users_devices_onboarding_rendered_map.png`
- `users_devices_onboarding_rendered_cheatsheet.png`

- `output/pdf/users_devices_onboarding_pack.pdf`
- `output/pdf/users_devices_recovery_drills_pack.pdf`

Extra rendered drill pages:

- `users_devices_recovery_drills_pack_page_1.png`

To rebuild the PDF pack:

```powershell
python scripts/render_users_devices_onboarding_pack.py
```
