# FSD — Webcam Capture Station

## Purpose

Create a simple desk intake station for Peter and Hayley.

## Hardware

Starter:

- phone camera
- USB webcam
- good lighting
- plain desk mat
- optional overhead phone mount

## Dashboard behaviour

- show live preview if available
- capture image
- retake image
- save to capture inbox
- choose capture type
- link now or sort later

## Capture presets

- receipt
- asset
- part/bin
- QR proof
- repair/damage
- prototype
- workbench

## V1 fallback

If webcam integration is not available, use drag/drop and file picker first.
