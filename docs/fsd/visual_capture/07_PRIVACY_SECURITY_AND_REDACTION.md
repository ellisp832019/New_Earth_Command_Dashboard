# FSD — Privacy, Security and Redaction

## Sensitive images may include

- receipts
- addresses
- bank details
- serial numbers
- personal letters
- medical/personal items
- private home photos

## Required features

- sensitive flag
- private folder guidance
- redaction workflow
- do not commit images to repo
- local-first storage
- confirm before export

## Redaction actions

- crop
- blur
- mark private
- exclude from export
- move to sensitive review

## Rule

Visual Capture stores evidence, but privacy comes first.
