# FSD — Asset and Parts Photo Attachment

## Purpose

Attach photos to assets, tools, parts, bins, shelves and projects.

## Photo types

```text
asset_front
asset_back
serial_number
warranty_label
parts_bin
shelf_location
qr_label_applied
repair_damage
prototype_build
workbench_snapshot
```

## Workflow

1. Select or capture photo.
2. Choose type.
3. Link to asset_id, part_id, bin_id or project.
4. Save to Visual Capture folder.
5. Add record to index CSV.
6. Show photo gallery on Asset page.

## Asset page should show

- main photo
- serial photo
- QR label photo
- warranty photo
- repair photos
- location/bin photo
