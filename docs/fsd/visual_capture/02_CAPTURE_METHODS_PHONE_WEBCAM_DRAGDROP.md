# FSD — Capture Methods

## Recommended hybrid setup

```text
Phone Camera
= fast/mobile capture

Webcam Capture Station
= desk workflow, receipts, parts, QR labels

Overhead Camera
= future lab/workbench intelligence
```

## V1 capture methods

- drag/drop image upload
- choose file from disk
- open capture inbox folder
- attach existing image to record

## V2 capture methods

- webcam capture inside Dashboard
- save directly to capture inbox
- basic image preview
- retake button

## V3 capture methods

- mobile capture workflow
- phone import folder
- QR scan + photo attach
- overhead workbench snapshots

## Capture Station UI

Buttons:

- Capture receipt
- Capture asset
- Capture part/bin
- Capture QR proof
- Capture repair/damage
- Capture workbench snapshot

## Calm mode

One button:

```text
Quick Capture
```

It saves image to inbox and asks questions later.
