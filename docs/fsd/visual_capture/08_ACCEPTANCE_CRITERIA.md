# FSD — Acceptance Criteria

## Must pass

- Visual Capture path is read from `config/local_paths.json`.
- Visual Capture tab or sub-tab appears in Dashboard.
- App validates `19_VISUAL_RECORDS_AND_CAPTURE`.
- App can open capture inbox.
- App can import image by file picker or drag/drop.
- App can index image in CSV.
- App can link image to receipt, asset, part, QR label or project.
- App does not store raw images in Dashboard repo.
- App does not break Treasury, Assets or QR labels.
- App never deletes user images.
- App can flag image as sensitive.
- App can create missing folders/files from templates.

## Nice to have

- Webcam capture.
- Thumbnail generation.
- OCR queue.
- Receipt OCR stub.
- Camera device profiles.
- Prototype timeline.
