# FSD — New Earth Dashboard Treasury Tab

## Purpose
Create a calm, simple, local-first finance control panel inside the New Earth Dashboard so Hayley can manage household and New Earth finance workflows without digging through folders.

## Source-of-truth folder
```text
D:\NEW_EARTH_OMEGA_OS_PACK\17_FINANCE_AND_TREASURY
```

## Users
### Hayley
Treasurer / Finance Queen. Needs clarity, calmness, low cognitive load, and simple guided workflows.

### Peter
Needs visibility on safe spending, watch areas, project costs, decisions needed, and receipts needed.

## Core principles
- Calm over complex.
- Fewer clicks.
- Local-first.
- No cloud requirement.
- Clear status cards.
- No shame, no blame, just clarity.
- Finance files remain in Omega OS.
- Dashboard reads and updates simple Markdown/CSV/JSON files.
