# FSD — Hayley Calm UX

## UX goal
Make finance feel grounded, safe, and easy.

## Use language like
- Safe
- Watch
- Pause
- Needs decision
- Future investment
- Done
- Sorted

## Avoid language like
- Failure
- Crisis
- Error
- Over budget panic
- Deficit

## Home cards
```text
🟢 Safe to Spend
🟡 Watch Areas
🔴 Pause Spending
🔵 Decisions Needed
```

## Low-energy mode
A 10-minute review mode:
1. Mark safe areas
2. Mark watch areas
3. Mark decisions
4. Save note
5. Done
