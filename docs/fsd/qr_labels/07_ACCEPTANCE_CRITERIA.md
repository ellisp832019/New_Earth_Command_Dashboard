# FSD — Acceptance Criteria

## Must pass v1

- QR Label section appears inside Asset Intelligence or as sub-tab.
- App can generate QR PNG for an asset ID.
- App can create label register rows.
- App can add jobs to print queue.
- App can save generated QR files to Omega OS.
- App can preview label text.
- App can mark labels printed/applied.
- QR payload contains asset ID only.
- App does not require Bluetooth printer for v1.
- App does not break Treasury or Asset Intelligence.
- App never deletes user files.
- App backs up before overwriting registers.

## Nice to have

- Label size selector.
- Bin label generator.
- Reorder tag generator.
- Maintenance tag generator.
- Printer profile manager.
- Manual scan lookup.
