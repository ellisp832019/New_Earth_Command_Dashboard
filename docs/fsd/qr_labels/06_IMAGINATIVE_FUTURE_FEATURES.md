# FSD — Imaginative Future Features

## 1. Sacred lab map

A calm visual map of the office/lab showing drawers, shelves, bins, test bench, MicroGrow area and BioCalm area.

## 2. Find my part

Search:

```text
VL53L5X
```

Dashboard tells you:

```text
Prototype Box 3 → Sensor Bag B
```

## 3. Scan-to-journal

Scan an asset and quickly add test result, fault note, wiring note, firmware version or lesson learned.

## 4. Reorder blessing queue

Instead of impulse buying, scanned reorder tags go into a calm queue:

- useful now
- wait
- future
- not needed

Treasury can approve later.

## 5. Repair altar

A repair-focused view for broken tools, repair notes, parts needed, cost to fix and replacement option.

## 6. Prototype lineage

Track which parts went into which prototype.

```text
BioCalm Prototype V0.2
├── Sensor board NE-BC-SENSOR-0004
├── ESP32-S3 NE-MG-ESP32-0012
└── Enclosure NE-CASE-0007
```

## 7. Asset valuation timeline

Show how physical assets, prototypes and stock contribute to business value over time.

## 8. Hayley calm mode

A simplified view showing only labels to print, labels applied, things needing receipts and reorders needing decisions.
