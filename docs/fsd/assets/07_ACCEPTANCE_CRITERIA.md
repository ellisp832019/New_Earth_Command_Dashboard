# FSD — Acceptance Criteria

## Must pass

- Asset Intelligence tab appears in Dashboard navigation.
- App reads `assets_equipment_path` from `config/local_paths.json`.
- App does not require asset folder to be inside repo.
- App validates asset folder and required subfolders.
- App can create missing tracker files from templates.
- App can read/write equipment register.
- App can read/write parts inventory.
- App can show low stock items.
- App can show broken/repair items.
- App can show project asset summaries.
- App can link records to Treasury receipts.
- App backs up before writing.
- App never deletes user files.
- App does not break Treasury feature.

## Nice to have

- QR label register.
- Photo links.
- Supplier ratings.
- Valuation summary.
- One-minute quick capture.
- Reorder suggestions.
