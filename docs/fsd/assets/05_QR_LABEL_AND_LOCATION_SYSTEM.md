# FSD — QR Label and Location System

## Goal

Prepare Asset Intelligence for future QR label scanning.

## Label IDs

Examples:

```text
NE-EQ-0001
NE-MG-ESP32-0001
NE-BC-SENSOR-0001
NE-TOOL-0001
```

## QR target

For v1, QR can point to a local asset markdown file or asset ID search.

Future dashboard behaviour:

1. Scan QR.
2. Open item page.
3. Show location, receipt, notes, status, project and maintenance.

## Location system

Use friendly names like Office Shelf A, Electronics Drawer 2, Prototype Box 4, MicroGrow Test Bench, Hayley Desk, and Storage Box 1.
