# FSD — Calm UI and Productivity Spec

## UX goal

Make inventory feel easy and useful, not like a warehouse system.

## Top cards

- 🟢 Available
- 🟡 Low stock / watch
- 🔴 Broken / repair
- 🔵 Needs decision
- 🟣 Wishlist
- ⚪ Archived

## Asset Home

Show:

- total assets
- low stock items
- broken items
- recent purchases to register
- reorder decisions
- project asset totals

## Quick Add Item

Minimum fields:

- name
- type
- project
- location
- status

Everything else can be added later.

## Low-energy mode

Allow a one-minute asset capture:

```text
Item name:
Where is it:
Project:
Photo later? yes/no
```

## Tone

Use available, low stock, needs sorting, needs decision, repair needed, and registered.

Avoid error, failure, missing compliance, and inventory exception.
