# Module Status Guide

- `planned`: concept only.
- `scaffold`: routes or placeholders exist.
- `prototype`: useful exploration exists, but the module is incomplete.
- `functional`: core workflow works locally, but hardening is still in progress.
- `alpha`: meaningful implementation with known gaps.
- `beta`: broad workflows work and are tested.
- `release_candidate`: release-ready apart from final approval.
- `stable`: release evidence and documentation are complete.
- `parked`: intentionally deferred.
- `deprecated`: superseded.
