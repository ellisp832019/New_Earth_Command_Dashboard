## Priority Summary

- P0: None found. The current app supports meaningful work.
- P1: F-01, F-02, F-03, F-04, F-05, F-06.
- P2: F-07 through F-15.
- P3: F-16 and F-17.

## Authority Risks

The most important risks are not data corruption risks; they are interpretation risks. The Dashboard-local database owns authored operational state, Platform Core owns declared architecture, NEOS/repo intelligence owns observed engineering truth, GAIA owns interpretation, and Command Centre owns orchestration. The UI needs to keep those scopes visible when similar terms such as status, health, command, project and company appear together.

## Safe Simplification Principle

The safest early work is labeling, grouping, contextual linking and shared status language. Removing routes, merging authorities, or moving writes between feature repositories is not safe to infer from this audit alone.
