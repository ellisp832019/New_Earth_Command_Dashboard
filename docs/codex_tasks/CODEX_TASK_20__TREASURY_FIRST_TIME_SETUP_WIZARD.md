# CODEX TASK 20 — Treasury First-Time Setup Wizard

## Goal

Create a calm, first-time Treasury setup wizard that seeds Hayley personal pots, your personal pots, and shared household pots in one guided flow, with New Earth business pots available as an optional lane.

## Scope

1. Add a first-time setup wizard to Treasury Budget Pots.
2. Default the wizard to Hayley, you, and shared household packs.
3. Let New Earth business pots be selected as an optional pack.
4. Keep the existing starter pack actions available for direct use.
5. Preserve local-first, backup-safe writes and keep existing pots untouched.

## Expected Result

Hayley can open Treasury once, choose the core money lanes, and seed both personal finance structures in a single calm setup flow without having to build the pot structure by hand.
