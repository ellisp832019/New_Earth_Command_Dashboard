# Codex Task 03 — Link Photo to Treasury, Asset or QR

## Goal

Allow images to be linked to other systems.

## Link targets

- Treasury finance record
- receipt entry
- asset_id
- part_id
- bin_id
- qr_label_id
- project
- repair/maintenance record

## Rule

Visual Capture owns the image record.

Other systems reference the visual capture ID or file path.
