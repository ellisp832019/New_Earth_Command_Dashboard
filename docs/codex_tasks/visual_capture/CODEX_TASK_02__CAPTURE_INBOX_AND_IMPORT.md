# Codex Task 02 — Capture Inbox and Import

## Goal

Build the capture inbox and import flow.

## Features

- View inbox folder.
- Import image by file picker.
- Drag/drop image where supported.
- Copy file into inbox.
- Add record to `visual_capture_index.csv`.
- Preview image.
- Mark capture type.

## Capture types

- receipt
- asset
- part_bin
- qr_proof
- serial_warranty
- repair_damage
- prototype
- workbench
- project_progress
