# Codex Task 04 - Result Reuse and Comparison

## Goal

Make experiment outcomes easier to compare, understand, and reuse across the dashboard.

## Requirements

- Add a side-by-side comparison view for recent experiments.
- Surface repeated lesson themes so patterns are visible.
- Add quick reuse actions from the experiment detail panel.
- Let the user turn an experiment into a task, journal entry, learning item, or content idea.
- Keep the feature local-first, calm, and review-first.

## Suggested UI changes

- Show the latest experiments side by side in the results area.
- Highlight repeated lesson themes across the workspace.
- Add a reuse card inside the experiment detail panel.
- Prefill the destination form with experiment title, objective, lesson, conclusion, and next actions where useful.

## Acceptance Criteria

- The user can compare two recent experiments without leaving the workspace.
- Repeated lesson themes are visible in the results area.
- The user can convert an experiment into follow-up work with minimal retyping.
- The app still analyzes cleanly after the change.
