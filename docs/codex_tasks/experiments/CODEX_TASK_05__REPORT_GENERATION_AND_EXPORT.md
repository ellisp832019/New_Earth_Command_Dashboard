# Codex Task 05 - Report Generation and Export

## Goal

Make it easy to turn the experiment workspace into a local markdown report that can be saved, copied, and reused elsewhere.

## Requirements

- Generate a calm markdown summary from the workspace.
- Include the latest experiments in the generated report.
- Surface repeated lesson themes in the report body.
- Save the report into the module's local storage folder.
- Let the user copy the generated markdown for reuse.
- Keep the feature local-first and review-first.

## Suggested UI changes

- Add a workspace report card to the Reports section.
- Show a preview of the generated markdown.
- Add buttons to save the report and copy the markdown.
- Keep the existing report template list visible.

## Acceptance Criteria

- The user can generate a report without leaving the experiment workspace.
- The report is saved into the local module storage folder.
- The user can copy the same report text for reuse elsewhere.
- The app still analyzes cleanly after the change.
