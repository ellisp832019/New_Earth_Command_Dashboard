# Codex Task 03 - Templates and Quick Starts

## Goal

Make the experiment create flow faster by adding reusable starter templates for common experiment types.

## Requirements

- Add starter templates for common experiment patterns.
- Preload the create form from the selected template.
- Keep the templates calm and single-step.
- Let the user reset the form back to the selected starter.
- Keep the feature local-first and review-first.

## Suggested Templates

- Project validation
- Workflow test
- Build / hardware check
- Learning experiment
- Research check

## Suggested UI changes

- Add template chips to the create section.
- Show the template description beside the chips.
- Preload the title, project, objective, hypothesis, plan, notes, and next actions fields.

## Acceptance Criteria

- The user can start a draft without filling every field from scratch.
- The selected starter is obvious on screen.
- The reset action returns the form to the selected starter.
- The app still analyzes cleanly after the change.
