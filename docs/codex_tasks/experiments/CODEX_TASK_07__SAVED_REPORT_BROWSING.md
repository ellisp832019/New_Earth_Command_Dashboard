# Codex Task 07 - Saved Report Browsing

## Goal

Make the saved experiment report archive visible and easy to reopen from the Reports section.

## Requirements

- List saved markdown reports in the Reports section.
- Sort the list with newest reports first.
- Let the user open any saved report with one click.
- Keep the report output root visible.
- Keep the feature local-first and review-first.

## Suggested UI changes

- Add a saved reports list below the report export card.
- Show the filename and path for each saved report.
- Add an `Open` action for each file.

## Acceptance Criteria

- The user can see saved markdown reports without leaving the workspace.
- The user can open a saved report file from the list.
- The app still analyzes cleanly after the change.
