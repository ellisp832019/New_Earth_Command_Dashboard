## Scope

1. Add an owner group to Treasury budget pots so personal, shared, and New Earth money can live in the same calm file but stay clearly separated.
2. Keep the existing Treasury status states intact for Safe / Watch / Pause / Decision.
3. Add starter packs for Hayley personal pots, your personal pots, shared household pots, and New Earth business pots.
4. Let Hayley create pots through the UI with an owner selector and quick starter pack actions.
5. Keep the local-first backup-safe save behaviour unchanged.

## Expected Result

Hayley can open Budget Pots and immediately seed a personal finance structure for herself, you, and the household. Each pot is clearly labelled by owner and ready for calm daily use without needing to build the structure by hand.
