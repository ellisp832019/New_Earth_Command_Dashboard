# Treasury Architecture Overview

```text
Omega OS finance folder = source of truth
Dashboard app = calm visual interface
Dashboard repo = code and docs only
```

## Data approach
- Markdown for human-readable notes
- CSV for simple trackers
- JSON for dashboard state
- Backups before writing
- Local-first, no cloud required
