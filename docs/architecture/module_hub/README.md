# Module Hub Architecture Reference

This folder contains the architecture reference for the New Earth Dashboard Module Hub UI.

## Files

- `module_hub_architecture.md` explains the module hub shell, registry, dock, permission, and health placeholders.
- `visuals/new_earth_module_hub_architecture.png` is the clean visual reference image for the shell.
- `visuals/new_earth_module_hub_architecture_status.png` is the latest annotated build-proof image.
- `visuals/build_proof/` stores the preserved image history for previous architecture passes.
- `knowledge_fabric_sync_architecture.md` groups the end-to-end bridge, sync, and vault diagrams for the local-first knowledge fabric flow.
- `visuals/knowledge_fabric_sync_architecture_*.png` contains the four companion knowledge-fabric diagrams.

This Module Hub slice sits alongside the local knowledge-fabric tooling:

- [Obsidian sync module](../../../modules/NE_OBSIDIAN_SYNC_MODULE/README.md)
- [Repo intelligence bridge](../../../modules/NE_REPO_INTELLIGENCE_BRIDGE/README.md)
- [Project index](../../../PROJECT_INDEX.md)

- [Architecture Visual Index](../visual_index.md)

## Use

Keep this folder inside the dashboard repo as the build reference for the Module Hub slice and future contributors.
