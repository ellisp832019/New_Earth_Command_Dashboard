# Peter — Asset Workflow

## When you buy something

1. Put receipt in Treasury.
2. Add item to Asset Inbox or Quick Add.
3. Link item to project.
4. Add location.
5. Add status.
6. Add notes if it taught you something.

## Quick capture is enough

Minimum:

- Item name
- Project
- Location
- Status

You can add receipts, serials, notes, manuals and valuation later.
