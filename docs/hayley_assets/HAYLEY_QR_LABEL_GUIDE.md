# Hayley — QR Label Guide

This is designed to make physical things easier to find and track.

You do not need to understand the technical details.

## Your simple workflow

1. Open Labels.
2. Look at Ready to Print.
3. Print labels.
4. Stick label on item/bin.
5. Mark Applied.

## Printer note

- Use the thermal label printer flow for label rolls.
- Use `Epson XP-3200` only for paper printouts like checklists or reference pages.
- If you are printing a checklist, open the Windows print dialog and select `Epson XP-3200`.

## Calm rule

If unsure, leave it in the queue.

Nothing has to be perfect.
