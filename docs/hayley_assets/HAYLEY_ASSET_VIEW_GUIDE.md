# Hayley - Asset Intelligence Guide

This guide is the simple way to use the Assets tab without getting buried in file names or spreadsheet thinking.

The goal is not to manage everything at once.
The goal is to keep equipment, parts, repairs, and spending decisions clear enough to act on.

## What the Assets tab is for

Use Assets when you need to see:

- what New Earth owns
- what is low in stock
- what is broken or needs repair
- what needs a spending decision
- what needs a receipt or finance link
- what needs a label, location, or valuation note

## First step

1. Open the app.
2. Go to `Assets`.
3. Check the top hero card.
4. If it says the folder is linked and ready, you can start using the registers.
5. If it says setup is needed, follow the folder health prompts first.

## The easiest daily flow

1. Open `Assets`.
2. Look at the `Priority focus` card.
3. Open the next best action.
4. Use `Quick Capture` if you need to save something fast.
5. Move into the register that matches the job.
6. Keep the note short.
7. Come back to the home screen when you want the next clear step.

## The first three moves

1. Capture fast.
2. Check stock.
3. Review repair.

If you do only those three things well, the rest of the tab will already feel useful.

## What each main card means

- `Available` means items are ready or settled in place.
- `Low Stock` means parts are at or near reorder level.
- `Broken / Repair` means equipment needs attention.
- `Needs Decision` means there is a choice to make.
- `Wishlist` means nice-to-have items parked for later.
- `Project Asset Summary` means assets grouped by project.

## Step by step: what to do when something arrives

1. Open `Quick Capture`.
2. Enter the item name.
3. Choose whether it is `Equipment` or `Part`.
4. Add the project.
5. Add the location.
6. Add the status.
7. Add short notes if needed.
8. Save it.

Use `Quick Capture` when the item is new and you do not want to spend time perfecting it.

## Step by step: when you need to check equipment

1. Open `Equipment Register`.
2. Find the item.
3. Check the status.
4. Check the location.
5. Check the project.
6. Check whether the receipt link exists.
7. Update the notes if anything important changed.

Use this when you want the full list of equipment in one place.

## Step by step: when you need to check parts

1. Open `Parts Inventory`.
2. Find the part.
3. Check the quantity.
4. Check the minimum quantity.
5. Check the supplier.
6. Check the last cost.
7. Use the low stock card if it needs reorder attention.

## Step by step: when stock is getting low

1. Open `Low Stock / Reorder`.
2. Read the low stock list.
3. Check which parts are most urgent.
4. Look at the reorder suggestions.
5. Compare the estimate with the current need.
6. Decide whether to reorder now or park it briefly.

This is the best screen for a quick reorder scan.

## Step by step: when equipment is broken

1. Open `Broken / Repair`.
2. Check the broken or repair items.
3. Read the short notes.
4. Decide whether it is repairable or needs replacement.
5. If money is involved, check the linked Treasury summary card.

## Step by step: when you need to log maintenance

1. Open `Maintenance Log`.
2. Add the date.
3. Add the asset ID.
4. Add the issue.
5. Add the action taken.
6. Add the status.
7. Add the cost if there was one.
8. Add the linked finance record if it exists.

Use this for repairs, servicing, calibration, or follow-up work.

## Step by step: when you need a supplier or order

1. Open `Supplier Register` to keep supplier details tidy.
2. Open `Orders Tracker` when you want to see orders and spend links.
3. Open `Reorder List` when you want to see what needs buying next.
4. Keep supplier names and order notes short and consistent.

## Step by step: when you need a location

1. Open `Location Register`.
2. Check where the item is stored.
3. Add a clear location name like a shelf, drawer, bench, or box.
4. Add a photo link if it helps.
5. Keep the wording simple enough that someone else can find it later.

## Step by step: when you need valuation or insurance detail

1. Open `Valuation Summary`.
2. Check the purchase cost.
3. Check the replacement value.
4. Check the current estimate.
5. Check the evidence link.
6. Look at the project summary if you need the bigger picture.

Use this when you need a calm view of what the assets may be worth.

## Step by step: when you need a label

1. Open `QR Labels`.
2. Check the asset ID and label code.
3. Add the target path if needed.
4. Add the printed date when the label is used.
5. Keep the label code consistent with the asset ID.

## Step by step: when you need to do a stocktake

1. Open `Inventory Session`.
2. Enter the session name and who is counting.
3. Build the weekly pack.
4. Open the latest PDF or CSV and print it if needed.
5. Walk equipment and parts together, shelf by shelf.
6. Use the follow-up list for unlabeled equipment and low-stock parts.
7. Export the unlabeled or low-stock CSV when you need a smaller action list.
8. Keep the notes short and calm so the next person can continue easily.

For a printable one-page version, use [Hayley and Ellis Inventory Session Checklist](HAYLEY_INVENTORY_SESSION_CHECKLIST.md).

## What the sync card is for

The `Asset sync` card helps you see whether the journal is connected and whether conflicts are showing.

Use it when you want to:

- refresh the journal state
- check conflict count
- see who last wrote to the journal
- confirm the last change time

If you need to update the view, use `Refresh journal`.

If conflicts are showing, use `Review Conflicts`.

## How to handle conflicts

If the app shows a conflict, it does not mean the asset work is broken.
It means two edits touched the same record and the app wants you to review them calmly.

1. Open `Review Conflicts`.
2. Read the record name.
3. Check the machine names.
4. Check the change count.
5. If the latest edit is clearly the one to keep, use `Compact journal to latest`.
6. Decide what the clean record should be.
7. Keep the review short and neutral.

## Simple rules to remember

1. Use `Quick Capture` first if you are in a hurry.
2. Use the matching register second.
3. Keep notes short and useful.
4. Link receipts when money is involved.
5. Use `Low Stock` for buying decisions.
6. Use `Broken / Repair` for equipment decisions.
7. Use `Valuation Summary` when you need value context.
8. Use `Review Conflicts` only when the journal asks for it.

## If the tab says setup is needed

1. Open the folder health card.
2. Check the listed missing folder or file.
3. Use the starter structure button if available.
4. Reopen `Assets`.
5. Start again from `Priority focus`.

## The main idea

Keep Assets calm.
Keep it local.
Keep the records easy to trust.
If you only do one thing well, do the next clear step and leave the rest parked until you need it.
