# Responsive Validation

The Dashboard programme intelligence workspace must remain usable at the supported Windows desktop sizes:

- 1280x720
- 1366x768
- 1600x900
- 1920x1080

Validation targets:

- no RenderFlex overflow
- no clipped primary status information
- no fixed-width layout breakage
- scrollable content remains reachable
- navigation remains usable in the read-only shell

The two-tab host layout keeps the host surface compact while allowing the package-owned views to scroll internally.
