# Project Officer Question Catalog

## Question Classes

1. Current repository state
2. Current protected main commit
3. Controlled baseline provenance
4. Release readiness status
5. Why release readiness is blocked
6. Highest-priority unresolved risks
7. Which risks are stale
8. Which modules are weak or stale
9. Which verifications are stale
10. Which CI gates passed or failed
11. What changed since the controlled baseline
12. Whether live Git differs from recorded metadata
13. Which evidence supports the recommendation
14. What should be worked on next
15. Which project control records matter for a module
16. Which data is missing or conflicting
17. Whether GitHub state is available and current
18. Which future work package should be prepared

## Answer Requirements

Every class should support:

- a direct answer
- a short explanation
- evidence references
- freshness notes
- uncertainty when needed

## Question Boundaries

Questions outside the read-only evidence model should be redirected or refused.
Examples:

- make this change for me
- approve this release automatically
- rewrite this risk status
- push the branch

## Evidence Discipline

If the answer depends on a live value, cite the observation source.
If it depends on a checkpoint, label it as recorded.
If it depends on a scan, label it as derived.
