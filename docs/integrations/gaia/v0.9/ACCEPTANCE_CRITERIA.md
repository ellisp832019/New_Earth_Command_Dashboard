# Acceptance Criteria

GAIA v0.9 architecture is acceptable when:

- the Dashboard keeps GAIA read-only
- live state and recorded state are explicitly distinct
- provenance and freshness are surfaced in the contract
- questions are answered with evidence references
- stale or missing data is not hidden
- the source allowlist is documented
- prompt injection boundaries are defined
- the threat model is recorded
- the responsibility boundary is clear
- the cross-repository split is explicit
- JSON schemas validate
- examples match the schemas conceptually
- Project Control registration was reviewed
- no runtime mutation capability was added
- the branch is ready for human review only
