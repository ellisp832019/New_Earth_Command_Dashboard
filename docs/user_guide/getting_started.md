# Getting Started

New Earth Command Dashboard is a local-first app for turning a large mission into a clear daily plan.

The V0.1 direction is simple:

1. Open the Dashboard.
2. Choose today's focus.
3. Pick the Top 3 tasks.
4. Work from Projects, Tasks, or Planner.
5. Capture notes, ideas, and progress.
6. Review the day.
7. Carry forward what still matters.

## Current App State

The current build is an app shell. It includes:

- Dashboard-first launch.
- Bottom navigation for Dashboard, Projects, Tasks, Planner, and More.
- Placeholder screens for the main MVP modules.
- More screen links for Journal, Learning, Content, Business, Wellbeing, Inbox, and Settings.
- Material 3 New Earth theme.
- Local database foundation prepared for later tasks.

## Main Navigation

Use the bottom navigation for the five primary areas:

- Dashboard: daily focus and overview.
- Projects: active New Earth project areas.
- Tasks: actions across projects.
- Planner: morning planning and evening review direction.
- More: supporting modules.

## Supporting Modules

The More screen keeps the app calm by holding secondary areas:

- Journal.
- Learning.
- Content.
- Business.
- Wellbeing.
- Inbox.
- Settings.
