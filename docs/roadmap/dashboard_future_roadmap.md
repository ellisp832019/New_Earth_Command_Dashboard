# Dashboard Future Roadmap

This roadmap focuses on the future of the main New Earth dashboard as a calm command centre.

The goal is not to make the home screen busier.
The goal is to make it more useful, more readable, and more predictable.

## Guiding Rules

1. Keep the dashboard local-first and offline-first.
2. Keep the home screen calm and focused on the next useful action.
3. Prefer one clear hierarchy over many equal-weight cards.
4. Keep access, session, and voice state visible without making them noisy.
5. Make the dashboard easier to scan before making it richer.

## Phase 1 - Home Clarity

Focus on the core "what do I do next?" view.

Targets:

- keep the Today hero as the first thing the user reads
- keep Top 3 tasks as the primary action surface
- keep active projects visible but secondary
- keep the session/access strip quiet and readable
- keep quick capture available without stealing attention

Success looks like:

- the dashboard answers the next action in one glance
- the user can open the app and immediately orient themselves
- the screen feels calm even when several modules are active

## Phase 2 - Dashboard Card Consistency

Make every dashboard card feel like it belongs to the same system.

Targets:

- align spacing, icon blocks, and header rhythm across cards
- keep summary cards short and easy to read
- make button groups consistent across modules
- preserve strong visual separation between dashboard cards and module screens

Success looks like:

- cards feel like part of one design language
- the dashboard no longer feels patched together
- the user can predict how actions are grouped

## Phase 3 - Session And Access Layer

Make security visible without making it intrusive.

Targets:

- keep the top-left session pill live
- show active user, online state, and expiry countdown clearly
- keep the warning colour shift for nearing timeout
- keep Security Lock and Access Matrix one tap away

Success looks like:

- the session state is always easy to trust
- lock and access controls stay available without cluttering the main view
- the user can recover quickly if the session changes

## Phase 4 - Daily Flow Tools

Strengthen the day-to-day operating loop.

Targets:

- improve the Top 3 loop
- keep Quick Capture fast and low-friction
- keep project summaries short and helpful
- make task and planner handoff smoother

Success looks like:

- the dashboard actively supports planning and follow-through
- the user does not need to hunt for the next action
- the screen stays useful even on low-energy days

## Phase 5 - Personalization And Control

Let the user shape the dashboard without breaking the calm layout.

Targets:

- allow some cards to be hidden or reordered
- keep the dashboard lightweight by default
- preserve a clear fallback layout if customization is turned off

Success looks like:

- the dashboard adapts to the user without turning into a mess
- personal preference improves the layout instead of fragmenting it

## Parked For Later

These should stay out of the dashboard core until the home screen is stable:

- heavy analytics
- live cloud sync
- account/login flows
- broad integration surfaces
- noisy automation that competes with the daily plan

## First Build Slice

If we start on this roadmap immediately, the first slice should be:

1. tighten the dashboard home hierarchy
2. keep the Top 3 / active projects / quick capture rhythm readable
3. make the session pill and access controls feel intentional
4. keep module entry points consistent with the dashboard card style
