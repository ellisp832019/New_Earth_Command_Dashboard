# Project Now / Next / Later

This document is a calm top-level snapshot of the whole New Earth Command Dashboard project.

It is meant to show:

- what is already built and working
- what should be hardened next
- what is deliberately parked for later

## Now

These areas are already active and should be treated as the current working core:

- Dashboard shell and local-first app foundation
- Tasks, Planner, Projects, Journal, Inbox, Learning, Content, Business, Wellbeing
- Treasury and Assets/QR workflows
- Knowledge Library and PDF catalogue work
- Voice capture and Voice Assistant polishing
- Module Hub browsing, detail, operations, docking, and release polish
- Repo Intelligence / Obsidian sync cleanup and templating

## Next

These are the most sensible follow-on slices once the current core remains stable:

1. Finish voice polish
2. Harden QR and print flows
3. Keep Knowledge Library reliable and useful
4. Verify and polish Inbox processing
5. Complete V0.1 release-readiness checks
6. Add the safe AI adapter contract and stub
7. Keep the Repo Intelligence Bridge and Obsidian sync reusable across repos
8. Improve dashboard customization only after the core loop stays calm

## Later

These are intentionally future-facing and should stay parked until the core is stronger:

- AI providers beyond the local stub
- Always-listening voice mode
- Calendar integration
- GitHub integration
- WordPress integration
- MicroGrow live links
- Cloud sync
- Drag-and-drop / multi-window Module Hub docking
- Richer cross-module intelligence and search
