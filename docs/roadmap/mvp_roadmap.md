# MVP Roadmap

The MVP should grow in small, reviewable slices. Do not build the whole app at once.

## Current Foundation

Completed:

- Flutter app shell.
- Material 3 New Earth theme.
- `go_router` navigation.
- Bottom navigation.
- Placeholder feature screens.
- More screen links.
- Drift and SQLite database foundation.
- MVP database tables.

## Next Recommended Slices

1. Add seed data for default New Earth projects.
2. Wire Projects screen to local data.
3. Add basic project list and project detail flow.
4. Add task creation and task list.
5. Add Top 3 task selection for Dashboard.
6. Add Daily Planner data flow.
7. Add Journal capture.
8. Add Learning, Content, Business, and Wellbeing data screens.
9. Add backup/export once core local data is stable.

## Design Rule

Each slice should make the app more useful without increasing overwhelm.

Use "Parked" and "Carry Forward" language where work is paused or moved, and keep the Dashboard focused on today's useful action.
