# NE Obsidian Sync Module

Local-first Obsidian and Omega OS documentation sync for New Earth projects.

The module scans the current repo, generates Obsidian-ready Markdown notes, and optionally mirrors them into a configured vault folder.

## What It Produces

- `START_HERE.md`
- `INDEX.md`
- `DOC_REGISTRY.md`
- `PROJECT_OVERVIEW.md`
- `CURRENT_STATE.md`
- `CURRENT_PROGRESS.md`
- `ARCHITECTURE.md`
- `ROADMAP.md`
- `MILESTONE_SUMMARIES.md`
- `CHANGE_INTELLIGENCE.md`
- `RISK_TRACKER.md`
- `DECISIONS.md`
- `DECISIONS_LOG.md`
- `BUILD_LOG.md`
- `BUILD_LOG_SUMMARY.md`
- `CODE_MAP.md`
- `TASKS.md`
- `OPEN_QUESTIONS.md`
- `WEEKLY_REPORT.md`
- `FULL_BUILD_HISTORY.md`
- `DAILY_SYNC_LOG.md`

## How It Works

1. Read `obsidian_sync_config.json`.
2. Scan the source repo and watched folders.
3. Regenerate the export Markdown files.
4. Copy the exports into the configured vault destination.
5. Apply the configured note prefix when mirroring into Obsidian.
6. Preserve hand-written vault content outside the autogenerated block.

## Safety Model

- Only content inside `<!-- AUTO-GENERATED:START -->` and `<!-- AUTO-GENERATED:END -->` is replaced automatically.
- If a destination note has hand-written content outside that block, it is left intact.
- If a note does not yet have markers, the sync tool appends one managed block instead of wiping the file.
- Sync runs are local-first and do not require cloud services.

## Manual Sync

From the module root:

```powershell
python .\scripts\sync_obsidian.py sync
```

Or use the wrapper:

```powershell
.\scripts\sync_to_obsidian.ps1
```

## Watch Mode

Keep watching the repo for changes and resync automatically:

```powershell
.\scripts\sync_to_obsidian.ps1 -Watch
```

Or:

```powershell
python .\scripts\sync_obsidian.py watch
```

## New Earth Fit

This module is tuned for:

- New Earth Dashboard
- Omega OS related repos
- local-first dashboards and operational tools
- markdown-based project memory in Obsidian

## Vault Layout

For this repo, the synced notes are intended to land in:

```text
D:/NEW_EARTH_OMEGA_OS_PACK/09_KNOWLEDGE_VAULT_OBSIDIAN/NEW_EARTH_OMEGA_KNOWLEDGE_VAULT/01_ACTIVE_PROJECTS
```

The vault-facing files are prefixed like this:

```text
NEW_EARTH_DASHBOARD_PROJECT_OVERVIEW.md
NEW_EARTH_DASHBOARD_START_HERE.md
NEW_EARTH_DASHBOARD_DOC_REGISTRY.md
NEW_EARTH_DASHBOARD_CURRENT_PROGRESS.md
NEW_EARTH_DASHBOARD_INDEX.md
NEW_EARTH_DASHBOARD_BUILD_LOG.md
```
