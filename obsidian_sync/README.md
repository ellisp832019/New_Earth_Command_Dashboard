# NE Obsidian Sync Module

Local-first Obsidian and Omega OS documentation sync for New Earth projects.

The module scans the current repo, generates Obsidian-ready Markdown notes, and optionally mirrors them into a configured vault folder.

## What It Produces

- `PROJECT_OVERVIEW.md`
- `CURRENT_PROGRESS.md`
- `DECISIONS_LOG.md`
- `BUILD_LOG.md`
- `CODE_MAP.md`
- `TASKS.md`
- `OPEN_QUESTIONS.md`
- `DAILY_SYNC_LOG.md`

## How It Works

1. Read `obsidian_sync_config.json`.
2. Scan the source repo and watched folders.
3. Regenerate the export Markdown files.
4. Copy the exports into the configured vault destination.
5. Preserve hand-written vault content outside the autogenerated block.

## Safety Model

- Only content inside `<!-- AUTO-GENERATED:START -->` and `<!-- AUTO-GENERATED:END -->` is replaced automatically.
- If a destination note has hand-written content outside that block, it is left intact.
- If a note does not yet have markers, the sync tool appends one managed block instead of wiping the file.
- Sync runs are local-first and do not require cloud services.

## Manual Sync

From the module root:

```powershell
python .\scripts\sync_obsidian.py sync
```

Or use the wrapper:

```powershell
.\scripts\sync_to_obsidian.ps1
```

## Watch Mode

Keep watching the repo for changes and resync automatically:

```powershell
.\scripts\sync_to_obsidian.ps1 -Watch
```

Or:

```powershell
python .\scripts\sync_obsidian.py watch
```
