# About the New Earth Dashboard

## Purpose

The New Earth Dashboard is the central command interface for organising, building, tracking, and expanding the New Earth technology ecosystem.

It connects projects, modules, documents, tasks, grants, finance, knowledge systems, local AI, repository workflows, and Omega OS folder structures into one usable operating layer.

## What the Dashboard is for

The Dashboard helps answer four core questions:

1. What am I building?
2. What needs doing next?
3. Where does each file, module, idea, or decision belong?
4. How do all systems connect together safely and cleanly?

## Core connected systems

- New Earth Dashboard
- Omega OS folder system
- Module Hub UI
- Obsidian Vault
- VS Code repositories
- Codex development workflow
- Local AI / GAIA assistant layer
- Grants and funding tracker
- Finance and treasury records
- Backup and recovery system
- Project command centres
- Hardware and software modules

## Design principles

- Local-first where possible
- Clear folder ownership
- Human-readable documentation
- Modular architecture
- Security before automation
- Auditability and traceability
- One source of truth for each system
- Practical build-first development

## Current stage

This Help Centre is designed for the early Dashboard build stage. It should grow with the system and become the main support layer for both the founder and future users.
