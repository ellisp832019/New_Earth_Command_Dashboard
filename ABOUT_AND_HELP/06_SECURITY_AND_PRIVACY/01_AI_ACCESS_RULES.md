# AI Access Rules

## Access levels

### Level 0 — No access
AI can only answer questions from chat context.

### Level 1 — Read-only
AI can inspect selected docs, paths, or summaries.

### Level 2 — Draft only
AI can prepare changes but cannot apply them automatically.

### Level 3 — Approved write
AI can write files only after human approval.

### Level 4 — Automated operation
Reserved for mature, audited workflows only.

## Never automate without approval

- Deleting files
- Sending emails
- Posting publicly
- Finance actions
- Legal documents
- Grant submissions
- Hardware control affecting safety
