# Getting Started

## First-time orientation

Start here when opening the New Earth Dashboard for the first time.

The Dashboard is not just a normal app. It is a control layer for managing a growing ecosystem of projects, modules, local tools, knowledge bases, funding routes, and automation systems.

## First 10-minute walkthrough

1. Open the Dashboard home screen.
2. Check the Module Hub to see available modules.
3. Open the About & Help Centre.
4. Read the System Map.
5. Open the Project Command Centre.
6. Confirm the Omega OS root path.
7. Check the Obsidian Vault link.
8. Confirm backup status.
9. Review active tasks.
10. Open the Roadmap to see current build direction.

## Key areas to understand

### Dashboard

The main visual interface.

### Module Hub

The docking system where individual modules are discovered, launched, and managed.

### Omega OS

The structured folder system where long-term files, exports, finance, grants, documents, media, and knowledge are stored.

### Obsidian Vault

The human-readable knowledge layer for notes, guides, project thinking, and linked documentation.

### Repositories

The build layer where code, modules, hardware files, and app components are developed.

## Rule of thumb

If it is code, keep it in the repo.
If it is operational evidence, export, funding material, finance, or long-term record, store it in Omega OS.
If it is thinking, notes, knowledge, or strategy, link or mirror it into Obsidian.
