# Quick Start Paths

Use these paths when you want to do something quickly without reading the whole manual.

## I am new — show me the basics

1. Read `00_OVERVIEW.md`.
2. Read `01_GETTING_STARTED.md`.
3. Open the System Map.
4. Open the Module Directory.
5. Review the Glossary.

## I want to manage a project

1. Open Project Command Centre.
2. Select or create a project.
3. Link the repo path.
4. Link the Omega OS project folder.
5. Add current milestones and tasks.
6. Attach relevant guides.

## I want to add a new module

1. Create module folder in the repo.
2. Add module metadata.
3. Add user guide.
4. Add developer guide.
5. Register it in Module Hub.
6. Add troubleshooting notes.
7. Add roadmap status.

## I want to track a grant

1. Open the Grants module.
2. Add grant name, funder, deadline, amount, eligibility, and stage.
3. Link application docs.
4. Add required evidence.
5. Add review reminders.
6. Export final copies into Omega OS.

## I want to use local AI safely

1. Open the Local AI Security Layer guide.
2. Confirm what data AI can access.
3. Confirm sandbox boundaries.
4. Check audit logging.
5. Avoid giving AI direct destructive permissions.
6. Use human approval for file writes, email, finance, and external actions.

## I want to fix a broken path

1. Open Troubleshooting.
2. Check whether the path belongs to repo, Omega OS, Obsidian, or external drive.
3. Update path config.
4. Re-run sync or module scan.
5. Log the fix in the changelog.
