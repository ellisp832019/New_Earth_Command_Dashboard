# Glossary

## Dashboard

The main visual interface for managing New Earth systems.

## Module Hub

The docking and launch area for Dashboard modules.

## Omega OS

The long-term structured file system for New Earth records, exports, assets, finance, grants, and knowledge.

## Obsidian Vault

The linked note and knowledge layer.

## GAIA

The local AI assistant layer.

## Local AI Security Layer

The governance, sandboxing, permissions, and audit layer that controls AI access.

## Repo Research Engine

A tool/module for turning repositories into structured knowledge.

## Project Command Centre

The module for managing projects, actions, milestones, risks, and decisions.

## Docking

The process of registering a module so the Dashboard can discover and launch it.

## Source of Truth

The authoritative location for a record or decision.
