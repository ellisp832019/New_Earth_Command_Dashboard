# Where Does This Belong?

Use this decision helper to keep the Dashboard, Omega OS, Obsidian Vault, and repositories clean.

## Code

Belongs in the repository.

## Final PDFs, grant files, finance records, evidence, exports

Belongs in Omega OS.

## Notes, thoughts, linked knowledge, strategy, explanations

Belongs in Obsidian, with links back to source files.

## Module implementation files

Belongs in the module folder inside the repo.

## User guides

Belongs in `ABOUT_AND_HELP/03_USER_GUIDES/` and can be mirrored into Obsidian if useful.

## Module profiles

Belongs in `ABOUT_AND_HELP/04_MODULE_DIRECTORY/`.

## Visual architecture maps

Belongs in `ABOUT_AND_HELP/05_SYSTEM_MAPS/` and optionally Omega OS visual folders for final exports.

## Old experiments

Belongs in archive, with a short summary explaining why it was archived.
