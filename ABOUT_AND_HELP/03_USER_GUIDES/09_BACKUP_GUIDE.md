# Backup Guide

The Backup module protects the Dashboard, Omega OS, repositories, Obsidian Vault, and key project assets.

## Backup priorities

1. Omega OS
2. Active repositories
3. Obsidian Vault
4. Dashboard config
5. Grant and finance records
6. Visual assets
7. Build packs and exports

## Minimum check

The Dashboard should show last backup date, backup drive status, failed jobs, and restore instructions.
