# Omega OS Guide

Omega OS is the long-term operating file structure for New Earth.

## What belongs in Omega OS

- Finance and treasury exports
- Funding documents
- Final PDFs
- Brand assets
- Visual maps
- Legal and admin documents
- Archived project records
- Evidence and reports

## What does not belong there by default

- Temporary build files
- Node modules
- Generated cache
- Experimental code unless archived intentionally
