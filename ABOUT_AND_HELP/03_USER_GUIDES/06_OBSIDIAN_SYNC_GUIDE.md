# Obsidian Sync Guide

Obsidian is the knowledge and thinking layer. It should not blindly duplicate everything in the repo. It should link, summarise, and index useful information.

## Sync rules

- Repo docs can be mirrored into Obsidian when useful.
- Omega OS records should be indexed, not always duplicated.
- Avoid circular sync loops.
- Keep source-of-truth clear in metadata.
