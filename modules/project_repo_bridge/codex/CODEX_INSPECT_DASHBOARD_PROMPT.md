# Codex Prompt: Inspect Dashboard Project/Task System

Use this first.

```text
Inspect this Dashboard repo and report where projects and tasks are currently stored. Do not change files yet.

Find:
1. Where project data lives.
2. Where task data lives.
3. How projects and tasks are linked.
4. What UI pages/components display projects and tasks.
5. Whether data is hardcoded, JSON, database-backed, Zustand/Redux/store-backed, or localStorage-backed.
6. The safest adapter points for the Project Repo Bridge.
7. Any risks before integrating the module.

Return a short architecture report and do not edit files.
```
