# Codex Review Checklist

Before accepting the Codex changes, check:

- [ ] It did not delete or move existing dashboard files unnecessarily.
- [ ] It created a clean meeting module.
- [ ] Omega OS path is configurable.
- [ ] Meeting folder creation works.
- [ ] Markdown templates are readable.
- [ ] `meeting_index.json` is created/updated.
- [ ] All Meetings page loads.
- [ ] New Meeting wizard works.
- [ ] Actions can be tracked.
- [ ] Decisions can be tracked.
- [ ] Follow-ups can be tracked.
- [ ] No cloud dependency was added.
- [ ] No secrets or API keys were committed.
