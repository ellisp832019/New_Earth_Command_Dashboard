# MeetingDashboard Component Spec

## Purpose

Show a calm overview of meeting activity across Omega OS projects.

## Cards

- Open Actions
- Waiting Follow-ups
- Meetings This Week
- Decisions This Month

## Sections

- Recent Meetings
- Upcoming Meetings
- High Priority Follow-ups
- Recent Decisions

## Required interactions

- click meeting to open detail
- click new meeting
- filter by project
- search meetings
