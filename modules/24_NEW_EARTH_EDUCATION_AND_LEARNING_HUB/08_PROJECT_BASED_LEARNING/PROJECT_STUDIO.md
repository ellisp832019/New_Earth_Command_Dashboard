# Project Studio

## Purpose
Let learners build real things connected to New Earth.

## Example projects
1. Build a safe LED circuit
2. Make a plant observation diary
3. Create a MicroGrow crop card
4. Read an ESP32 sensor
5. Design a calm BioCalm wearable screen
6. Make a youth care project plan for animals/community wellbeing
7. Create a food resilience poster
8. Build a mini environmental monitor
9. Write a responsible AI guide
10. Present a New Earth idea

## Project stages
- Brief
- Materials
- Safety
- Build
- Test
- Evidence
- Reflection
- Share
