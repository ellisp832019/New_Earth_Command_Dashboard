# Module Brief

## Module name
New Earth Education & Learning Hub

## Mission
To create a practical, safe, project-based learning environment that helps learners grow confidence, skills, self-awareness, technical ability, and real-world capability.

## Who it serves
- Peter and New Earth Advanced Technologies
- Hayley / family education support
- Young people and youth innovation programmes
- Schools and community groups
- Rehabilitation settings
- MicroGrow learners
- BioCalm learners
- Engineering apprentices
- Local-first technology students
- Future New Earth partners

## Key outcomes
Learners should be able to:
- Understand systems thinking
- Build small electronics projects
- Learn embedded software step by step
- Understand food growing automation
- Use AI responsibly
- Document experiments
- Reflect on learning
- Build a skills portfolio
- Complete guided projects
- Prepare for real-world work or enterprise

## Omega quality bar
The module should be:
- Calm
- Clear
- Modular
- Safe for young learners
- Local-first
- Expandable
- Practical
- Beautiful
- Documented
- Testable
- Connected to the wider dashboard
