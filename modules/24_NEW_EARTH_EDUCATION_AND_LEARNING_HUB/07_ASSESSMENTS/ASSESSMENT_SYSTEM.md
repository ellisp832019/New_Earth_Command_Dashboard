# Assessment System

## Assessment types
- Quick quiz
- Practical checklist
- Reflection review
- Project evidence
- Mentor sign-off

## Scoring philosophy
Progress over pressure. Assessment should show growth, not create fear.

## Practical evidence examples
- LED circuit photo
- Sensor reading log
- MicroGrow maintenance checklist
- BioCalm packet explanation
- AI prompt comparison
- Reflection entry

## Badge logic
A badge is earned when required lessons, project evidence, and reflections are complete.
