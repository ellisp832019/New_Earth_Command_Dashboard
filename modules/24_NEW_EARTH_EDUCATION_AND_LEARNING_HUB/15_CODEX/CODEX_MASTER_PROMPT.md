# Codex Master Prompt

You are implementing `24_NEW_EARTH_EDUCATION_AND_LEARNING_HUB` inside the New Earth Dashboard.

Build it to Omega standard.

## Requirements
- Feature-first architecture
- Clean separation of presentation, application, domain, and data
- Local-first storage
- Responsive UI
- Calm New Earth design language
- Accessible components
- Role-based views
- Mock repositories first
- Real repository interfaces prepared
- Tests for progress, lesson completion, badges, roles, and imports
- No cloud dependency for v1
