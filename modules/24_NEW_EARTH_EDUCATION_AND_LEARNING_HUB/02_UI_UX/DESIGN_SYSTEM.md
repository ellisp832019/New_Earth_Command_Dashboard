# Design System

## Tone
Calm, clear, supportive, practical.

## Visual style
- Natural tones
- Large readable type
- Low visual noise
- Accessible contrast
- Friendly cards
- Progress without pressure

## Key UI components
- PathwayCard
- LessonCard
- SkillBadge
- ProgressRing
- ProjectChecklist
- ReflectionCard
- TutorPanel
- MentorNoteCard
- EvidenceTile
- SafetyBanner
- ContentPackCard

## Accessibility
- Large text option
- Dyslexia-friendly spacing
- Keyboard navigation
- Screen reader labels
- No flashing visuals
- Clear error states
