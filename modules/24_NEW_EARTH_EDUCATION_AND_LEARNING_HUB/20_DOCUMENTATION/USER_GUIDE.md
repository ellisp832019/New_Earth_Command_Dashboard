# User Guide

## For learners
1. Open Education Hub.
2. Choose a pathway.
3. Start the next lesson.
4. Complete the activity.
5. Save a reflection.
6. Add evidence if needed.
7. Review your skills passport.

## For learners in the first build
1. Open the Education & Learning Hub from More.
2. Use the search bar or audience chips to narrow the view.
3. Search across learners, lessons, projects, certificates, reflections, and source notes.
4. Use Reset filters in Pathways or Lesson Library if you want to return to the calm default view.
5. Open the Learning Pathways tab and choose a pathway.
6. Move to the Lesson Library and open a lesson card.
7. Use Practical Projects to open the project workspace and save a local checkpoint.
8. Review the evidence log inside the project workspace to see project progress history.
9. Review Student Progress for the local snapshot and badge readiness.
10. Use the suggested next step inside Student Progress to choose the calmest useful action.
11. Try the AI Tutor placeholder for a safe suggestion-only flow.
12. Open Certificates & Badges to see the local learning passport.
13. Use Content Builder to draft or review an offline learning pack, add a semantic version, check validation, review the checksum and bundle id, press Save draft, and export the pack note plus PDF plus manifest.
14. In Reflection Journal, use Add reflection to save a quick local note with mood and body text.
15. Link a reflection to a lesson or project when you want the note attached to a real learning step.
16. In Assessments, read the mentor notes, rubric bands, score breakdown, and evidence refs before you sign anything off.
17. In Reports, use the learner chips and time-window chips to narrow the latest mentor report, certificate draft, and content pack outputs.
18. Use the Reports tab to export a fresh mentor report, issue a draft certificate, or reopen the preview PDFs.
19. Open Community / Classroom Mode to review the learner group, role-aware support lens, and mentor handoff view.
20. In Settings, use the offline pack controls to import or export the local bundle and open the latest draft shortcuts.
21. In Learning Pathways, watch the unit and lesson progress badges to see the active learner's route.
22. In Mentor Workspace, use Add mentor review to save sign-off notes and a handoff status locally.
23. Check the mentor review workflow and mentor review log when you need the latest review state before handoff.
24. In Settings, open the latest content pack PDF, content pack manifest, or certificate PDF when you want a quick review preview.

## For mentors
1. Open Mentor View.
2. Select learner.
3. Review progress.
4. Add notes.
5. Sign off badges.
6. Export report.

## For mentors in the first build
1. Open Mentor Workspace.
2. Select the learner card at the top.
3. Review the latest notes and reflections.
4. Use the local mentor summary to copy a handoff snapshot if needed.
5. Use the classroom / guardian lens to review the support tone.
6. Export a mentor report when you need a fuller handoff note.
7. Check the assessment cards and progress records.
8. Use the mentor note starter to capture a short handoff note.
9. Check the certificate readiness summary and preview before sign-off.
10. Use the draft certificate action when local assessment evidence is ready and the draft meets the local eligibility rules.
11. Open Settings if you need to copy the latest local report or certificate path.
12. Use the placeholder tutor only as guidance.
13. Keep any important decisions human-reviewed.

## For admins
1. Import content packs.
2. Manage pathways.
3. Configure AI tutor.
4. Review safety settings.

## For admins in the first build
1. Open Settings.
2. Review the module root and offline-first flags.
3. Review the local search and tutor placeholder hooks.
4. Use the project workspace evidence log to capture learning progress.
5. Use the Omega Knowledge Engine hook for future repository analysis.
6. Use Export content pack to write a full local snapshot bundle.
7. Use Import content pack to restore that bundle back into the module.
8. Use the passport summary copy action when you need a quick badge handoff note.
9. Use Draft certificate issuance to create a local certificate preview from completed assessments and readiness rules.
10. Open the latest certificate PDF path from Settings if you want the export-ready preview artifact.
11. Keep content local until production hardening is added.
