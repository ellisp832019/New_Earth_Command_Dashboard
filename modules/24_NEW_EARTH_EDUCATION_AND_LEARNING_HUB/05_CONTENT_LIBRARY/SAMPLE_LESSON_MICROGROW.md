# Sample Lesson: Reading Temperature and Humidity

## Summary
Use a sensor to understand how a grow environment changes over time.

## Learning outcomes
- Explain temperature and humidity
- Read sensor data
- Record environmental observations
- Connect data to plant health

## Activity
1. Open the MicroGrow dashboard.
2. Read current temperature and humidity.
3. Record three readings over time.
4. Note what changed in the room.
5. Suggest one improvement.

## Reflection
How could this data help plants grow better?
