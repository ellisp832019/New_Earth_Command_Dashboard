# Role-Based Access

## Roles
- Learner
- Mentor
- Guardian
- Teacher
- Admin

## Learner permissions
- View assigned content
- Complete lessons
- Save reflections
- Upload local evidence
- Ask AI tutor questions

## Mentor permissions
- Assign pathways
- Review progress
- Add notes
- Sign off badges

## Guardian permissions
- View progress
- View safety notes
- Support reflections

## Admin permissions
- Manage content packs
- Manage roles
- Export reports
- Configure AI tutor
