# Offline Content Packs

## Content pack contents
- pathways.json
- units.json
- lessons/*.md
- quizzes.json
- projects.json
- assets/images
- assets/diagrams
- version.json

## Import/export
The module should import/export content packs as zip files.

## Versioning
Each content pack should include:
- id
- title
- version
- author
- createdAt
- compatibility
- changelog
