# Developer Notes

## Where to add future content
- Put new learning pathways in `04_LEARNING_PATHWAYS/`
- Put lesson templates and lesson examples in `05_CONTENT_LIBRARY/`
- Put AI tutor prompt ideas in `06_AI_TUTOR/`
- Put assessment changes in `07_ASSESSMENTS/`
- Put project learning structure in `08_PROJECT_BASED_LEARNING/`
- Put offline pack rules in `10_LOCAL_FIRST_DATA/`

## What stays read-only for now
- No cloud sync
- No live tutor automation
- No authentication layer changes
- No background write-back to Omega OS files

## Safe extension points
- Add new repository data in `lib/features/education_learning_hub/data/`
- Add presentation widgets in `lib/features/education_learning_hub/presentation/`
- Add new domain objects in `lib/features/education_learning_hub/domain/`

## Content structure
- Keep titles short and calm
- Prefer step-by-step lessons
- Use reflection prompts after each practical activity
- Keep mentor notes readable and human-friendly
