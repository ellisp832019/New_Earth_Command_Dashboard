# Readiness Score Rules

Each grant gets a score out of 70.

| Category | Score |
|---|---:|
| Project Summary | 0-10 |
| Budget | 0-10 |
| Evidence | 0-10 |
| Partner Support | 0-10 |
| Impact Case | 0-10 |
| Commercial Plan | 0-10 |
| Risk Management | 0-10 |

## Dashboard interpretation

```text
0-20   Very weak. Do not submit.
21-35  Early draft. Needs work.
36-50  Possible. Strengthen before submission.
51-60  Good. Submit if deadline is near.
61-70  Strong. Submit after final checks.
```

## MicroGrow first target

Aim for at least 45/70 before submitting a prototype grant.
