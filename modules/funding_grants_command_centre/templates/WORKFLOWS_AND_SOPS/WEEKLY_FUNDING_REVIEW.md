# Weekly Funding Review

Run this once per week.

## 1. Deadlines

- What is due in the next 7 days?
- What is due in the next 30 days?
- What has no deadline yet?

## 2. Pipeline

Count applications by status.

## 3. Next actions

Every active application must have one clear next action.

## 4. Evidence

Check whether each active application has:
- photos
- screenshots
- test reports
- partner notes
- budget
- risk register

## 5. Funding totals

Record:
- requested
- pending
- approved
- rejected

## 6. Lessons

Review any rejected grants and extract reusable improvements.
