# Grant Lifecycle SOP

## 1. Opportunity found

- Save link
- Create intake form
- Set status to Researching
- Add deadline
- Add amount
- Add eligibility notes

## 2. Eligibility checked

If good fit:
- set status to Eligible

If poor fit:
- set status to Paused
- save reason

## 3. Drafting

- create application.md
- create budget.md
- create evidence_pack.md
- create risk_register.md

Set status to Drafting.

## 4. Evidence check

If evidence is weak:
- set status to Needs Evidence

## 5. Budget check

If budget is weak:
- set status to Needs Budget

## 6. Partner check

If support letter is required:
- set status to Needs Partner

## 7. Ready to submit

Only move to Ready to Submit when:
- application complete
- budget complete
- evidence complete
- risks checked
- partner letters attached if needed
- final copy reviewed

## 8. Submitted

After submission:
- save final copy
- save confirmation
- move folder to Submitted
- update tracker

## 9. Decision

If approved:
- move to Approved
- create reporting folder
- add claim dates

If rejected:
- move to Rejected
- save feedback
- write lessons learned

## 10. Close

After all reports and claims are complete:
- move status to Closed
- archive final snapshot
