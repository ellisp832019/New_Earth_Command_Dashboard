# MicroGrow One-Page Grant Summary

## Project title

MicroGrow Prototype Validation

## One-line summary

MicroGrow is a local-first smart grow automation system designed to help people learn, grow food and manage controlled environments without depending on cloud infrastructure.

## Problem

Small growers, educators and community projects often lack affordable, understandable and locally controlled automation tools for indoor growing.

## Solution

MicroGrow combines ESP32-based environmental monitoring, relay control, a Flutter app, local network operation, evidence-led diagnostics and a safe low-voltage prototype pathway.

## Innovation

- local-first operation
- low-cost modular hardware
- education-ready design
- rehabilitation and skills pathway
- clear hardware/software evidence trail
- scalable architecture from prototype to pilot

## Funding use

The funding will support prototype refinement, PCB V0.1, enclosure development, safety documentation, app polish, testing and pilot-readiness documentation.

## Expected outcomes

- working prototype kit
- documented test results
- improved enclosure and usability
- pilot-ready evidence pack
- clearer route to education/community/rehabilitation deployment
