# Future AI Assistant Specification

This is not required for v1, but the module should be designed so AI assistance can be added safely later.

## AI assistant jobs

- summarise grant opportunities
- check eligibility
- draft first-pass application answers
- compare application against scoring criteria
- identify missing evidence
- create budget notes
- turn rejected feedback into improvements
- generate reporting drafts

## Safety rules

- AI should not submit applications.
- AI should not invent evidence.
- AI should mark assumptions clearly.
- AI should cite source files when using Omega OS evidence.
- Final application decisions stay with Peter.
