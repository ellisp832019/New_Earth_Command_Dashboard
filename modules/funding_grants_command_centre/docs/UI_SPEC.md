# UI Specification

## Main screen

Title:

```text
Funding & Grants Command Centre
```

Top stats:

- Total requested
- Total pending
- Total approved
- Total rejected
- Applications due this month
- Average readiness score

## Views

### Pipeline View

Columns:

- Idea
- Researching
- Eligible
- Drafting
- Needs Evidence
- Needs Budget
- Needs Partner
- Ready to Submit
- Submitted
- Under Review
- Approved
- Rejected
- Paused
- Reporting Phase
- Closed

### Grant Card

Show:

- grant name
- project
- amount
- deadline
- status
- next action
- readiness score
- risk badge

### Grant Detail

Tabs:

- Overview
- Application
- Budget
- Evidence
- Partners
- Risks
- Reporting
- Lessons

### Evidence View

Checklist grouped by:

- photos
- videos
- screenshots
- test reports
- technical docs
- user feedback
- partner letters
- impact evidence

## Design feel

This should feel like a serious finance and command centre module, not a basic notes list.
