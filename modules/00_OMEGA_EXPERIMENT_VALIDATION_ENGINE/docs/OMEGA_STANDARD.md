# Omega Standard

This module is Omega Standard when it meets these principles:

## Local-first

All core files are readable local files: markdown, JSON, CSV and folders.

## Evidence-first

No claim is trusted unless linked to evidence.

## Reusable knowledge

Every completed experiment must generate at least one lesson learned or design rule.

## Tool-agnostic

The module supports common software but does not depend on any single vendor.

## Human-readable

A folder can be opened without the dashboard and still make sense.

## AI-ready

Files are structured so local AI can read, summarise and review them later.

## Dashboard-ready

The dashboard reads the same JSON records used by automation scripts.

## Repo-ready

The module can live inside a Git repository and be version controlled.
