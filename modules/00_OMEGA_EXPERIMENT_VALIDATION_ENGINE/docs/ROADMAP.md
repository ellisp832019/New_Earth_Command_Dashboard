# Roadmap

## Phase 1 — Foundation

- Add module folder to dashboard repo
- Register module in dashboard module hub
- Use templates manually
- Store experiments as JSON + markdown
- Use local evidence folders

## Phase 2 — Automation

- Run `create_experiment.py`
- Auto-generate Obsidian notes
- Auto-generate GitHub issue bodies
- Import CSV results
- Generate markdown reports

## Phase 3 — Dashboard UI

- Experiment Command Centre
- Active experiment list
- Evidence viewer
- Result comparison screen
- Lessons learned database

## Phase 4 — Engineering integrations

- Proteus evidence indexing
- KiCad evidence indexing
- Fusion evidence indexing
- PlatformIO serial log import
- Firmware commit linking

## Phase 5 — AI Review

- Local AI summary pipeline
- Experiment Copilot
- Design review prompts
- Failure analysis assistant
- Next-test recommendations

## Phase 6 — Omega Intelligence

- Cross-project design rule extraction
- Sensor/component recommendation memory
- Reusable engineering standards
- Funding/report export packs
