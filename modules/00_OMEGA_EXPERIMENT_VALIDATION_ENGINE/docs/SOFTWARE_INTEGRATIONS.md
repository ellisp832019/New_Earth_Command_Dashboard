# Software Integrations

## VS Code

Primary editing and automation environment.

Use for:

- editing experiment notes
- running Python scripts
- Codex integration
- dashboard module development
- reviewing JSON records

## GitHub

Use for:

- issue tracking
- experiment task history
- pull request links
- release traceability
- firmware commit references

## Obsidian

Use for:

- long-form experiment journal
- knowledge graph
- lessons learned
- links between projects
- engineering doctrine

## Proteus

Use for:

- circuit simulation
- microcontroller simulation
- Mist Driver stages
- relay logic
- fault logic
- waveform screenshots

Recommended evidence folder:

```text
evidence/proteus/
  project_files/
  screenshots/
  waveforms/
  notes/
```

## KiCad

Use for:

- schematic validation
- PCB layout evidence
- exported schematics
- BOM comparison
- pin map validation

## Fusion 360 / FreeCAD

Use for:

- enclosure design
- PCB fit checks
- airflow tests
- mounting systems
- export screenshots and STL evidence

## PlatformIO / Arduino IDE

Use for:

- ESP32 firmware builds
- serial logs
- unit tests
- pin validation
- firmware version linking

## Excel / CSV / LibreOffice Calc

Use for:

- test tables
- sensor logs
- scorecards
- comparison matrices

## Python

Use for:

- importing CSV logs
- generating markdown reports
- charting later
- validating schemas
- exporting summaries

## LTspice

Use for:

- analog simulation
- filters
- power sections
- sensor front ends
- current sense circuits

## Bench instruments

Track outputs from:

- oscilloscope
- logic analyzer
- thermal camera
- bench power supply
- multimeter
- USB power meter
