# MicroGrow Kickstarter Plan

## Recommended Goal

£35,000

## Reason

This is large enough to fund prototype refinement, PCB V0.1–V0.3, manufacturing samples, campaign content, fulfilment reserve, and contingency without pretending the full global ecosystem is ready.

## Campaign Promise

MicroGrow is a local-first grow automation system using ESP32 nodes, sensors, relay control, a hub architecture, and a Flutter app.

The Kickstarter should fund the next step from working prototype to beta/dev kit level hardware.

## What To Show

- Frankenstein prototype box
- ESP32 node
- Live sensor readings
- App control
- Relay switching
- One automation profile
- One grow environment
- Future architecture diagram
- Founder story

## What Not To Promise Yet

- Full multi-node mesh network
- Prison deployment product
- Final commercial PCB
- Certified mains controller
- AI marketplace
- Cloud ecosystem

These can be shown as roadmap/future vision, not V1 promises.
