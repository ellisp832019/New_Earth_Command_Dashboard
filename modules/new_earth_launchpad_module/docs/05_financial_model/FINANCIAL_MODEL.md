# Financial Model

## Starting Goal

£35,000

## Suggested Reserves

- Kickstarter platform fee: 5%
- Payment processing: estimate 3–5%
- Tax/VAT reserve: confirm with accountant before launch
- Contingency: 10–15%
- Fulfilment reserve: always include

## Critical Rule

Never price rewards by guessing.

For each tier calculate:

```text
Reward price
- cost of goods
- packaging
- shipping subsidy
- platform fees
- payment fees
- support time
- contingency
= actual margin
```

## Warning

Shipping can destroy campaign margins. Keep first physical rewards limited and controlled.
