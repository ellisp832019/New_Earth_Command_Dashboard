# Agent Rules — Company Command Centre

## Mission
Build and maintain the dashboard module that helps operate New Earth Advanced Technologies Ltd.

## Non-negotiables
- Use `D:\NEW_EARTH_OMEGA_OS_PACK\00_COMPANY` as the Omega OS company source path.
- Start read-only.
- Do not overwrite existing company records without a timestamped backup.
- Treat legal, tax, and finance content as tracking/support information, not professional advice.
- Keep the UI calm, clear, practical, and founder-friendly.

## Data principles
- Markdown files are the human-readable source of truth.
- JSON indexes are generated views for the dashboard.
- Every item should have status, owner, due date where relevant, and linked source path.
