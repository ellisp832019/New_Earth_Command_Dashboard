# Operating Manual

## Daily use
Check Director Action Board, urgent deadlines, grant tasks, and website/LinkedIn tasks.

## Weekly use
Every Friday:
- Update company action board
- Add evidence from the week
- Check grant pipeline
- Check product portfolio status
- Reconcile business spending notes

## Monthly use
At month end:
- Update finance summary
- Review product progress
- Capture IP/assets created
- Export monthly company report
- Back up company folder

## Evidence rule
Every meaningful build step should create evidence: screenshot, photo, test result, build log, video, README update, or architecture diagram.
