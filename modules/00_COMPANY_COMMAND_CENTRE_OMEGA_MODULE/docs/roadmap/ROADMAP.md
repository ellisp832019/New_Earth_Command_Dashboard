# Roadmap

## v0.1 - Shell
Static UI, mock data, and navigation.

## v0.2 - Read-only Omega OS bridge
Scan markdown records from `D:\NEW_EARTH_OMEGA_OS_PACK\00_COMPANY` and create dashboard indexes.
Current slice: the scanner now generates the local company, action, deadline, product, grants, IP asset, and evidence indexes for the dashboard, and the Index Explorer surfaces them in a searchable read-only view.

## v0.3 - Action board
Tasks, deadlines, filters, and weekly/monthly views.
Current slice: compliance, website, LinkedIn, and director board views now surface source-linked checklist content in calm read-only cards.

## v0.4 - Evidence library
Capture and link evidence for grants, products, IP, and marketing.

## v0.5 - Safe write-back
Create/update markdown files with backup and audit log.
Current slice: read-only/write mode switch, timestamped backups, audit trail, and exportable audit summary report.

## v1.0 - Company operating release
Stable module with reports, search, export, and weekly company brief.
