# UK Company Admin Checklist

This checklist is for internal tracking only and is not legal, tax, or accounting advice.

## Company records
- [ ] Companies House account available
- [ ] Authentication code stored securely
- [ ] Certificate of incorporation saved
- [ ] Articles of association saved
- [ ] Shareholder/director records saved
- [ ] Registered office details saved

## Banking
- [ ] Tide account active
- [ ] Debit card received/activated
- [ ] Bank details saved securely
- [ ] Business-only spending rule followed

## Tax/admin
- [ ] Corporation Tax activation reviewed
- [ ] Bookkeeping process chosen
- [ ] Receipt capture process created
- [ ] Accountant shortlist created
- [ ] PAYE reviewed if paying salary
- [ ] VAT reviewed when revenue grows or strategically useful

## Public presence
- [ ] Website live
- [ ] Company email live
- [ ] LinkedIn profile updated
- [ ] LinkedIn company page created
- [ ] Product pages drafted
