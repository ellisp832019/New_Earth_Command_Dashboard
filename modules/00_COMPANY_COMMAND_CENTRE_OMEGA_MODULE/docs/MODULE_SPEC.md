# Module Specification

## Module name
00_COMPANY_COMMAND_CENTRE

## Purpose
A command centre for managing the operating backbone of New Earth Advanced Technologies Ltd.

## Core outcome
The founder can open the dashboard and immediately see:

- What needs doing next
- What deadlines matter
- Which products/assets exist
- Which grants and partnerships are active
- What website/LinkedIn actions are pending
- Where company records live in Omega OS

## Module sections
1. Overview
2. Compliance & Deadlines
3. Finance Snapshot
4. Website & Brand
5. LinkedIn & Marketing
6. Product Portfolio
7. IP & Asset Register
8. Grants Pipeline
9. Partnerships
10. Evidence Library
11. Director Action Board
12. Settings

## First release scope
Read-only dashboard with mock data and links to Omega OS records.

## Later release scope
Safe write-back to markdown files, auto-generated reports, Companies House deadline reminders, grant status automation, and weekly company brief generation.
