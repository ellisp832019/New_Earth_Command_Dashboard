# UI Specification

## Overview page cards
- Company status
- Next deadline
- This week actions
- Product portfolio health
- Grants active
- Website/LinkedIn actions
- Finance/admin status

## Compliance page table
Columns: item, authority, due date, status, notes, source file.

Example items:
- Companies House confirmation statement
- Annual accounts
- Corporation Tax setup
- Company authentication code stored
- Registered office records

## Finance page
Track Tide status, bookkeeping, receipt capture, monthly reconciliation, accountant, VAT/PAYE review.

## Website & Brand page
Track domain, email, website pages, product pages, contact forms, SEO basics, and brand assets.

## Product Portfolio page
Cards for MicroGrow, BioCalm, Omega Dashboard, New Earth Living, Field Scanner, and New Earth Rehabilitation System.

## Grants page
Pipeline stages: Idea, Researching, Drafting, Submitted, Review, Awarded, Rejected, Archived.

## Director Action Board
Kanban lanes: Today, This Week, This Month, Waiting, Done.
