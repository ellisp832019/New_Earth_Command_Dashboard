# Starter Voice Commands

Safe starter commands:

- Gaia, open MicroGrow.
- Gaia, show today's dashboard.
- Gaia, open the Obsidian vault.
- Gaia, show my current project roadmap.
- Gaia, summarise the latest MicroGrow status.
- Gaia, create a draft task for the dashboard.

Sensitive commands require confirmation:

- Gaia, turn on relay one.
- Gaia, send this message.
- Gaia, edit finance records.
- Gaia, delete this file.
