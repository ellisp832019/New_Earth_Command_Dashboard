# Module Hub Architecture Reference

This folder contains the architecture reference for the New Earth Dashboard Omega Module Hub UI.

## Files

- `module_hub_architecture.md` — explanation and usage notes for the architecture flow.
- `visuals/new_earth_module_hub_architecture.png` — visual reference image for the module shell, dock system, permissions, services, and Omega OS integration.

## Use

Keep this folder inside the dashboard repo as the build reference for Codex, Copilot, and future contributors.
