# AI Assistant Dock

## Purpose

Local J.A.R.V.I.S-style dock for voice, local LLM, automation and hands-free control.

## First shell version

This module starts as a visible Module Hub card with a detail screen, permissions list, health placeholder, dock option and Omega OS record link.

## Future integration

Real functionality should be connected only after the Module Hub foundation is stable.

## Requested permissions

- microphone
- speaker
- screen_capture
- file_read
- file_write_project_only
- browser_control
- app_launch
- shell_commands_approval
- keyboard_mouse_approval
- local_network
- internet_access_optional
