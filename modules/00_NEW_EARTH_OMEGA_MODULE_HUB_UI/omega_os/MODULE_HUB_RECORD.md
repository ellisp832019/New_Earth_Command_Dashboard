# Omega OS Record — Module Hub UI

## Purpose

Create the first New Earth Dashboard module/plugin shell.

## Strategic reason

The dashboard needs to become an operating system rather than a single fixed app. The Module Hub creates a controlled place where current and future capabilities can be installed, viewed, enabled, secured and monitored.

## Current phase

Structure and UI first. Backend integrations later.

## Included modules

- AI Assistant Dock
- Alexa Voice Gateway
- Obsidian Sync
- Repo Research Engine
- Grants Tracker
- Backup System
- MicroGrow Control
- XR Workspace
- Finance & Treasury
- Project Command Centre
- Visual Asset Index
- Local AI Runtime
