# Restore Strategy

A backup is not complete until restore has been tested.

## Restore levels

### Level 1: Single file restore

Recover one file.

### Level 2: Project restore

Recover one project folder.

### Level 3: Omega OS restore

Recover:

```text
D:\NEW_EARTH_OMEGA_OS_PACK
```

### Level 4: Full New Earth restore

Recover the full `D:\` system.

## Restore safety

Never overwrite live files by default.

Restore into:

```text
D:\_RESTORE_TEST_AREA
```

first.
