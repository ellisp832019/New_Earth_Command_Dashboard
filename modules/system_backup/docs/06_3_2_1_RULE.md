# 3-2-1 Rule For New Earth

Keep:

1. One live copy  
   `D:\`

2. One local backup  
   External SSD/HDD

3. One off-site backup  
   Second SSD stored away from the PC

Recommended:

```text
D:\                         Live New Earth system
E:\NEW_EARTH_BACKUP          Local backup
Second SSD                    Off-site archive
```
