# Device Trust Model

| Level | Name | Meaning |
|---|---|---|
| 0 | Unknown Device | Seen but not trusted |
| 1 | Seen Device | Identified but not registered |
| 2 | Registered Device | Named and owned, limited access |
| 3 | Trusted Local Device | Approved for normal local operations |
| 4 | Admin Device | Allowed for admin areas with correct user |
| 5 | Critical System Device | Core infrastructure such as backup/local hub |

## Examples
- Unknown phone: Level 0
- Workshop tablet: Level 2
- MicroGrow Node: Level 3
- NEW_EARTH_DEV: Level 4
- Backup drive: Level 5
