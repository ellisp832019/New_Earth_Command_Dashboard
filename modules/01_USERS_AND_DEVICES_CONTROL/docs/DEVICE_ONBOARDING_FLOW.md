# Device Onboarding Flow

## Phase 1 manual onboarding
1. Identify device.
2. Name device.
3. Select device type.
4. Assign owner.
5. Set trust level.
6. Assign allowed actions.
7. Save device record.
8. Write audit event.

## Later onboarding
- QR code pairing
- Local pairing PIN
- USB serial identity
- Local network discovery
- Device certificates
- Signed MicroGrow firmware identity
