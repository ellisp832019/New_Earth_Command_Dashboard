# Security Rules

1. AI agents are identities, not invisible helpers.
2. Voice systems request actions first; they do not directly execute sensitive actions by default.
3. MicroGrow nodes are device-only identities.
4. Finance, backup restore, device trust changes, and AI system execution require strict permissions.
5. Every sensitive allow/deny creates an audit event.
6. Local-first data stays under the user's control.
7. Cloud sync, if added, must be optional and encrypted.
