# Project Overview

The New Earth Command Deck is the physical control surface for the New Earth Dashboard.

It is not just a content creator Stream Deck. It is a mission-control layer for:

- MicroGrow
- BioCalm
- New Earth Living
- New Earth Dashboard
- Omega OS
- Meeting system
- Knowledge Vault
- Launchpad and crowdfunding campaigns
- AI agents and Codex
- OBS recording and content creation

## Core idea

The Dashboard is the software brain.

Omega OS is the file and knowledge body.

The Command Deck is the physical nervous system.

## Design principles

- Local-first wherever possible
- Simple buttons before complex automation
- Manual override always available
- No cloud dependency for core workflows
- Every meeting, build session, and campaign action leaves a record
- Every button should either open, create, capture, trigger, or log something useful

## Success criteria

The project is successful when Peter can press one button and begin a clean, logged work session with the correct apps, folders, dashboard page, and notes ready.
