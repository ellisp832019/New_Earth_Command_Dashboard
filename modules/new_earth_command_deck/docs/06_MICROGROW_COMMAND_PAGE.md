# MicroGrow Command Page

## Purpose

A Stream Deck folder dedicated to MicroGrow.

## Buttons

| Button | Action |
|---|---|
| Open Repo | Open MicroGrow repo in VS Code |
| Firmware Build | Run PlatformIO build |
| Firmware Upload | Run upload command after confirmation |
| Serial Monitor | Open serial monitor |
| Hub Dashboard | Open local hub dashboard |
| Node Discovery | Open discovery tool |
| Sensor Data | Open sensor status page |
| Relay Test | Open relay test page |
| OTA Manager | Open local OTA workflow |
| ESP-NOW Monitor | Open ESP-NOW diagnostics |
| PCB V0.1 | Open hardware PCB folder |
| Test Report | Create test report file |
| Build Log | Create daily MicroGrow build log |
| Codex Handoff | Create MicroGrow Codex handoff |
| Architecture Map | Open MicroGrow architecture map |

## Safety rules

- No one-button dangerous relay/mains actions
- Confirm before firmware upload
- Confirm before OTA
- Separate low-voltage dev actions from future production hardware
- Log all test actions
