# Launchpad Command Page

A dedicated command page for Kickstarter/crowdfunding campaigns.

## Buttons

- Campaign Dashboard
- Budget Planner
- Rewards Builder
- Risk Register
- Prototype Proof Folder
- Video Script
- Demo Recording
- LinkedIn Post
- Email Update
- Backer FAQ
- Asset Library
- Campaign Timeline
- Press Kit
- Export Campaign Pack

## Campaign records

Each campaign should have:

```text
LAUNCHPAD/CAMPAIGNS/YYYY-MM_campaign_name/
├── 00_CAMPAIGN_BRIEF.md
├── 01_BUDGET.md
├── 02_REWARDS.md
├── 03_RISKS.md
├── 04_CONTENT_PLAN.md
├── 05_VIDEO_SCRIPT.md
├── 06_ASSETS/
├── 07_UPDATES/
├── 08_BACKER_FAQ.md
└── 99_EXPORTS/
```
