# Dashboard UI Spec

## Page Name
Repo Research Engine

## Main UI Sections

### Research Input
- repo local path
- future Git URL
- profile selector
- output location

### Results Overview
- file count
- relevance score
- docs found
- code files found
- risks found
- licence status

### Useful Files
Table columns:
- path
- category
- matched profile keywords
- flags

### Risks
Table columns:
- path
- reason
- severity
- recommended action

### Generated Outputs
- report markdown
- Codex prompt
- action checklist
- vault note
