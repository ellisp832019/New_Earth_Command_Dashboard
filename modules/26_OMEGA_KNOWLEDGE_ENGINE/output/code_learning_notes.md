# Codebase Learning Notes

## New Earth Dashboard

- Flutter app shell, module registry, and local dashboard orchestration.
- Learn the module hub before attempting any route changes.
- The most sensitive paths are Users & Devices and Treasury.

## MicroGrow

- Firmware-oriented project with local status notes and future hardware sync points.
- Keep build outputs and generated files out of scans.

## BioCalm

- Wearable-focused repo with health or device integration themes.
- Review feature boundaries before suggesting refactors.

## New Earth Living

- Product-facing Flutter app for local project storytelling.
- Useful for shared UI patterns and content structure.
