# Dashboard UI Specification

## Module Card

Title: Omega Knowledge Engine

Subtitle: Living knowledge system for all New Earth projects.

Actions:

- Open Engine
- Run Scan
- View Last Report
- Export to Obsidian

## Main Tabs

### Overview
Shows last scan, repo count, scanned file count, and knowledge health.

### Repositories
Lists configured repos and scan status.

### Scan Results
Displays repository index and discovered files.

### Learning Notes
Displays generated explanations and learning summaries.

### Architecture Map
Shows folder/module architecture and future diagrams.

### Comment Suggestions
Shows where comments/docstrings could improve learning.

### Project Memory
Shows decisions, milestones, lessons, and generated memory notes.

### Obsidian Export
Shows export location and export status.

### Settings
Repo paths, ignore rules, output paths, safety mode.

## Design Feel

- Premium Omega dashboard style
- Calm, clean, technical
- Dark/light compatible
- Cards for project summaries
- Status chips for scan health
- Clear warning before any source modification
